Netlify 관리자가 설정한 비밀번호를 입력해야 데이터에 접근할 수 있습니다.

처음 이용할 때는 배포 안내서의 환경변수 설정이 필요합니다.

갤럭시 사용법: 기본 거래정보는 화면 폭에 맞춰 표시됩니다. 상세 관리표 1~30은 컴퓨터와 동일한 5열 표이며 좌우로 밀어서 보실 수 있습니다. HTML 파일을 내 파일 앱에서 선택해 Chrome 또는 삼성 인터넷으로 열고, 📂 엑셀 파일 불러오기로 XLSX를 선택하세요. 수정한 후 ✓ 정보 저장을 누르면 로그인한 모든 기기의 공용 온라인 데이터에 저장됩니다. 중요한 자료는 반드시 엑셀 사본 다운로드로 주기적으로 백업하세요. 휴대폰에서는 원본 엑셀 직접 덮어쓰기가 지원되지 않을 수 있습니다.

데이터 보관

공유 저장 방식: 모든 기기가 이 사이트에 로그인해 같은 거래처 데이터를 사용합니다. 정보 저장을 누르면 서버에 반영되며, 다른 기기는 다른 기기 변경 불러오기 버튼으로 최신 정보를 확인합니다. 처음 엑셀을 불러오면 온라인 목록 전체가 교체되므로 주의하세요. 엑셀 내보내기는 백업 용도입니다. 공용 비밀번호를 외부에 공유하지 마세요. 주민등록번호·계정 비밀번호 등 민감정보는 업로드 전 제외하거나 별도의 접근 통제·보안 검토를 권장합니다.
