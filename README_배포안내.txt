거래처관리 — Netlify 공유저장 웹앱
=================================

이 ZIP은 Netlify에 배포하기 위한 전체 프로젝트입니다. 단독 HTML을 더블클릭하는 용도가 아닙니다.
사용자에게 공개되는 정적 HTML에는 실제 거래처 정보가 포함되지 않습니다.

■ 배포 (최초 한 번)
1. https://app.netlify.com 에 가입/로그인합니다.
2. GitHub 저장소에 이 폴더 안의 모든 파일을 올립니다 (공개 저장소라도 원본 엑셀이나 비밀키를 올리면 안 됩니다).
3. Netlify의 Add new project → Import an existing project에서 GitHub 저장소를 연결합니다.
4. Project configuration → Environment variables에서 아래 두 변수를 추가합니다.
     APP_PASSWORD       : 14자 이상의 강력한 공동 접속 비밀번호 (개인정보가 있다면 계정별 권한 관리 솔루션 권장)
     APP_SESSION_SECRET : 무작위 32자 이상 문자열 (APP_PASSWORD와 다르게)
   이 값들을 netlify.toml이나 HTML, GitHub 소스에 적지 마세요.
5. Deploy를 실행합니다. 이미 배포했다면 환경변수를 설정한 후 다시 배포합니다.
6. 생성된 https://...netlify.app 주소로 접속합니다.
7. 비밀번호로 로그인 후 관리자 컴퓨터에서 '엑셀 파일 불러오기'로 원본 xlsx를 선택합니다.
8. 이어서 다른 PC / 갤럭시에서는 같은 사이트 주소로 로그인합니다.

■ 사용
- 거래처 검색 후 정보 수정 → '✓ 정보 저장' 버튼을 누르면 서버에 저장됩니다.
- 다른 기기에서 '↻ 다른 기기 변경 불러오기'를 누르면 최신 내용이 표시됩니다.
- 신규 등록도 동일하게 '정보 저장'해야 합니다.
- 첫 번째 엑셀 업로드 이후 다른 엑셀을 다시 업로드하면 현재 거래처 목록 전체를 교체합니다.
- 월 1회 이상 '엑셀 사본 다운로드'로 수동 백업하시기 바랍니다.
- 한 사용자가 저장하는 동안 다른 사용자가 저장하면 충돌 오류를 표시하며, 기존 정보를 무작정 덮어쓰지 않도록 했습니다.
- 데이터는 Netlify 사이트의 Blobs 저장소에 저장되며 웹사이트를 재배포해도 이어집니다.

■ 보안 및 주의 사항
- 이 버전은 공동 비밀번호 방식입니다. 사용자별 계정/권한/MFA/접근 기록 등이 필요한 업무에는 적합하지 않습니다.
- 주민등록번호, 보안카드번호, 홈택스·여신 비밀번호 등 매우 민감한 정보는 업로드 전에 제거/별도 보관하세요.
- 연결된 기기마다 화면에 비밀번호가 표시되는 기존 사용자 요구대로 동작합니다.
- Netlify 계정에 이중 인증을 켜고 앱 접속 비밀번호를 외부에 공유하지 마세요.
- 비밀번호를 분실하면 Netlify 환경변수의 APP_PASSWORD를 바꾸고 재배포합니다.
- 웹앱은 공개 주소로 접속 가능하지만 데이터 API는 로그인 쿠키를 요구합니다.
- 변경사항은 '정보 저장' 버튼을 누를 때 확정됩니다.
- 데이터 백업, 접근 제어, 개인정보 처리 적법성, 충돌 관리 등은 운영자가 관리해야 합니다.

■ 제약
- Netlify에 실제 배포하고 사이트를 활성화하는 작업은 사용자의 Netlify 계정에서 수행해야 합니다.
- 이 프로젝트를 배포하지 않고 파일로 열면 클라우드 연결은 동작하지 않습니다.
- 현재는 Netlify 실서비스/갤럭시 실기기에서 전체 검증 전입니다.
